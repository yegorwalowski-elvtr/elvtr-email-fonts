# elvtr-email-fonts

Brand fonts hosted for email rendering via jsDelivr CDN.

Used by ELVTR onboarding email templates that require ABC Arizona Flare in clients that support `@font-face` (Apple Mail, iOS Mail, Outlook 365 web).

CDN: `https://cdn.jsdelivr.net/gh/yegorwalowski-elvtr/elvtr-email-fonts@main/<file>`
